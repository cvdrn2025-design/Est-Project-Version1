📐 Backup & Referensi Rumus Perhitungan Volume

1. Galian Tanah (m³)
Rumus: P x L x T
Contoh: Panjang 10m, Lebar 0.8m, Kedalaman 1m = 10 x 0.8 x 1 = 8 m³

2. Urugan Tanah (m³)
Rumus: Volume Ruang Kosong x Faktor Pemadatan
Faktor pemadatan tanah biasa ± 1.2 (20% penyusutan).

3. Pondasi Batu Gunung (m³)
Rumus Trapesium: ((L. Atas + L. Bawah) / 2) x T x Panjang
Contoh: L. Atas 0.4m, L. Bawah 0.8m, T 0.6m, P 20m = ((0.4+0.8)/2) x 0.6 x 20 = 7.2 m³

4. Besi Tulangan (kg)
Rumus: Jumlah batang x Panjang batang (m) x Berat jenis besi per meter
Berat jenis (kg/m): D10=0.62, D13=1.04, D16=1.58, D19=2.23, D22=2.98.
Atau alternatif: 0.006165 x d² x Panjang (d = diameter besi dalam mm).

5. Beton Cor (m³)
Rumus: P x L x T (balok/plat)
Contoh: Balok 0.3 x 0.6 x 20m = 0.3 x 0.6 x 20 = 3.6 m³

6. Bekisting (m²)
Rumus: Luas permukaan yang bersentuhan dengan beton
Balok (induk/anak) = (2 sisi samping + sisi bawah) x Panjang
Kolom = (4 sisi x Tinggi kolom).
